# سجلات وتشخيص Azizos — الإصدار 0.0.9

يحفظ التطبيق سجلاً مستقلاً لكل تشغيل داخل `%LOCALAPPDATA%\Azizos\Logs`، تحت حساب ويندوز الذي يشغّل العملية. زر **السجلات** يفتح المجلد. لا تُرسل السجلات إلى أي خدمة.

## الإصلاح التلقائي لمشاكل التطبيق

تعمل المعالجة عند اكتشاف المشكلة، ويوفر زر **فحص وإصلاح** فحص السجل والملفات المدمجة عند الطلب. يمنع قفل العمليات تغيير ملفات التطبيق أثناء تطبيق التويكات، ويستمر القفل إلى نهاية العمل حتى لو أغلقت الواجهة طلبها المعلق.

| الرمز | الحالة والمعالجة |
|---|---|
| AZ-2001 | إذا تعذر إنشاء سجل المستخدم، يجرب مجلد Azizos في مسار المستخدم المؤقت. وإذا اختفى مسار السجل أو فشلت كتابته، يعيد فتحه ويحاول حفظ الحدث مرة واحدة. يُعرض فشل المسارين بوضوح. |
| AZ-2002 | يفحص الملفات المستخرجة مقابل محتواها المدمج في EXE. عند فقدها أو تلفها، يستخرج نسخة جديدة ويتحقق منها قبل استخدامها؛ لا يكتب فوق المجلد القديم. |
| AZ-2003 | يعيد قيم اللغة والمظهر غير الصالحة إلى العربية والمظهر الفاتح. يحافظ على التفضيلات الصالحة ومفاتيح التخزين الأخرى. |
| AZ-2004 | إذا تعذر إنشاء تقرير سطح المكتب، يستخدم `%LOCALAPPDATA%\Azizos\Reports` قبل بدء أي تغييرات. تُحفظ القيم الأصلية وjournal في الأرشيف نفسه، ويظهر المسار الفعلي في النتيجة. |

تُسجل نتيجة المحاولة «سليم / أُصلح / تعذّر الإصلاح»، وسببها، ويعرضها قسم قابل للفتح في الواجهة والتقرير. هذه معالجات لملفات Azizos وحالة واجهته. لا تعيد تشغيل التويكات الفاشلة، ولا تعدّل حماية Windows أو تعريفاته أو خدماته لمعالجة خطأ غير محسوم. فشل كتابة التقرير بعد التنفيذ لا يؤدي إلى إعادة تطبيق الخطة.

كل سطر JSON مستقل يتضمن وقت UTC بالمللي ثانية، ومعرّف الجلسة والعملية، ورقم تسلسل، والمستوى، والمرحلة. يُدوّر الملف بعد نحو 1 MiB، ويُحتفظ بآخر 30 ملفاً؛ لذلك انسخ سجل المشكلة قبل أن تزيله عمليات التنظيف اللاحقة. يظهر تعذّر إنشاء السجل أو كتابته في معلومات التشخيص والنتيجة، ولا يدّعي التطبيق أن الحفظ نجح.

## محتوى التشخيص

- بدء التشغيل، وجاهزية النافذة، والإغلاق الطبيعي.
- فشل قراءة النظام والمتطلبات، ومعاينة التويكات.
- نتائج إجراءات التطبيق مع معرّف التويك وفهرس الإجراء وتصنيف الخطأ.
- أخطاء أوامر الجسر، وكتابة التقارير، وفك الملفات المدمجة، وتسليم التشغيل للمحسّن.
- Rust panic مع backtrace، وأخطاء JavaScript والوعود غير المعالجة وفشل موارد الواجهة. تُحد رسائل الواجهة إلى 40 حدثاً لكل تحميل لمنع حلقات الأخطاء.

تحتفظ تقارير سطح المكتب أيضاً بملف `errors.jsonl`، وتفاصيل التشخيص في `report.json` و`report.txt`. تبقى القيم الأصلية في أرشيف الاسترجاع؛ سجل الجلسة لا ينسخها كحقول إضافية.

## الرموز

هذه **أرقام دعم Azizos**، وليست بديلاً عن رمز Windows أو خروج البرنامج. يحفظ `native_code` الرمز إذا ظهر صراحة في النص الأصلي؛ وإلا يبقى فارغاً. يُحفظ النص الأصلي دائماً. التصنيف والحلول إرشادية، ويُستخدم «غير مصنف» عندما لا تكفي الأدلة.

| الرمز | التصنيف | الإجراء المقترح |
|---|---|---|
| AZ-1001 | صلاحيات | مراجعة تشغيل المسؤول وصلاحيات الهدف |
| AZ-1002 | ملف أو مورد مفقود | مراجعة المسار والملفات المدمجة |
| AZ-1003 | مكوّن COM غير مسجل | التحقق من توفر المكوّن بإصدار ويندوز |
| AZ-1004 | مساحة التخزين | توفير مساحة للنظام والتقرير |
| AZ-1005 | انتهاء المهلة | مراجعة حالة العملية قبل إعادة التنفيذ |
| AZ-1006 | إجراء أو هوية تشغيل غير مدعومة | مطابقة التنفيذ مع البلاي بوك |
| AZ-1007 | فشل التحقق | قراءة الحالة الفعلية ومتطلبات إعادة التشغيل |
| AZ-1008 | حفظ الحالة الأصلية | مراجعة صلاحيات ومساحة أرشيف التقرير |
| AZ-1009 | خروج أداة بخطأ | قراءة رمز الخروج والمخرجات الأصلية |
| AZ-1010 | عملية قيد التنفيذ | انتظار العملية الحالية |
| AZ-1011 | تعريف أو معاملات غير صالحة | مراجعة الكتالوج والاختيارات |
| AZ-1099 | سبب غير محسوم | إرسال السجل وخطوات إعادة المشكلة |
| AZ-1201 | متطلب غير متحقق | معالجة المتطلب ثم إعادة الفحص |
| AZ-1900 | خطأ داخلي / panic | إرسال السجل وموضع حدوث المشكلة |

عدم انطباق تويك أو كونه مطبقاً مسبقاً لا يتحول إلى خطأ. المتطلب غير المتحقق يظهر تحذيراً. إذا انقطعت الخطة فلا تُعرض أعداد نهائية مختلقة، وتُمنع إعادة التشغيل التلقائي من شاشة النتيجة غير المكتملة.

## حدود التغطية والتحقق

هذا التقاط للأخطاء المعالجة وRust panic وأخطاء الواجهة؛ ليس مولّد crash dump لأخطاء تحميل Windows قبل بدء العملية أو أعطال الذاكرة الأصلية أو انقطاع الكهرباء. لا يصلح Windows تلقائياً ولا يعيد تشغيل التويكات الفاشلة تلقائياً.

التحقق يشمل اختبارات تصنيف HRESULT وأكواد الخروج، وعدم تخمين أرقام من المسارات، وكتابة JSONL وتدويره على القرص، وملفات التقارير الفعلية، واختبارات واجهة بمحاكاة الجسر. التشغيل الفعلي للبرنامج على Windows منفصل عن محاكاة تطبيق التويكات.
